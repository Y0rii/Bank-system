# Bank System 🏦

A simple Java console application that simulates basic bank account operations.

## Features
- 💰 Deposit money
- 💵 Withdraw money (in multiples of 50)
- 📊 Check account balance
- 🚪 Exit the program

## How It Works
The program displays a menu and lets the user choose an operation using a `switch` statement inside a loop, until they choose to exit.

## Technologies
- Java
- `Scanner` class for user input
